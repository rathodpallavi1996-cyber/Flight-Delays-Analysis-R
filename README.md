# Flight Delays Analysis Using R

## Project Overview

This project analyzes flight delay data using R to explore patterns related to flight schedules, airlines, weather, departure times, and delay status.

This project was completed as part of my Simplilearn R project work.

## Objectives

- Perform exploratory data analysis
- Identify missing values and understand the dataset
- Analyze factors related to flight delays
- Explore the effect of weather and other factors on delays
- Create visualizations to identify patterns

## Analysis Performed

- Data exploration and missing-value analysis
- Descriptive statistics
- Histograms
- Scheduled vs. actual departure time analysis
- Box plot analysis
- Departure hour analysis
- Carrier vs. delay analysis
- Delay status analysis
- Flight delay distribution using a pie chart

## Tools & Technologies

**R | RStudio | readxl | Plotly**
